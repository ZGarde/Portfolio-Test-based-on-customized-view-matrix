# 如何解读回测结果

## 1. 如何看 `rolling_backtest_performance_summary.csv`

这是 Stage 3 最重要的汇总表。建议按以下顺序看：

1. `strategy`
2. `window`
3. `rebalance_frequency`
4. `final_portfolio_value_net`
5. `annualized_return_net`
6. `annualized_volatility`
7. `sharpe_ratio_net`
8. `max_drawdown`
9. `average_turnover`
10. `total_transaction_cost`

## 2. final equity 高是否一定好

不一定。最终净值高可能来自高风险暴露或极端行情。必须结合最大回撤和波动率看。

## 3. Sharpe ratio 高说明什么

Sharpe ratio 衡量单位波动获得的收益。高 Sharpe 通常代表风险调整后表现更好。但如果收益分布有极端尾部风险，仅看 Sharpe 不够。

## 4. max drawdown 为什么重要

最大回撤代表从高点到低点的最大亏损。它体现投资者真实持有压力。一个高收益但最大回撤很大的策略，未必适合稳健组合。

## 5. annual return 和 annual volatility 如何一起看

年化收益高但波动也高，可能只是承担了更多风险。稳健策略应该同时有合理收益和可控波动。

## 6. 为什么 net return 比 gross return 更重要

gross return 不扣交易成本，net return 扣除交易成本。真实交易更接近 net return。

## 7. 如何判断交易成本是否过高

看：

- `average_turnover`
- `total_turnover`
- `total_transaction_cost`
- gross 和 net 表现差距

如果策略 gross 好但 net 明显变差，说明换手率过高。

## 8. 如何判断策略是否依赖单一资产

查看：

```text
rolling_backtest_weights.csv
rolling_backtest_risk_contribution.csv
```

如果某个资产长期接近 50% 上限，或风险贡献长期占大头，说明组合可能过度依赖单一资产。

## 9. 如何看 risk contribution

权重不等于风险贡献。低波动资产即使权重大，风险贡献也可能小；高波动资产即使权重低，风险贡献也可能大。

## 10. 如何看 weight evolution

查看图：

```text
data/processed/charts/rolling_weight_evolution.png
```

如果权重频繁跳动，可能导致高换手和高交易成本。

## 11. 如何判断 custom factor view 是否有价值

看：

- `rolling_backtest_custom_factor_log.csv`
- `rolling_custom_factor_signal_vs_gold_weight.png`
- Custom BL 与 Conservative BL 的净值和回撤差异

即使 Custom BL 表现好，也不能直接证明 custom factor 有效，因为结果可能来自协方差、约束或市场环境。

## 12. 为什么 Minimum Variance 表现好是合理的

样本期包含高波动阶段。Minimum Variance 通常降低风险资产暴露，因此可能有更高 Sharpe 和较低回撤。这说明风险控制有效，不代表 Black-Litterman 框架失败。

## 13. 为什么 BL Conservative 可以作为主模型

Conservative BL 的优点是：

- views 简单；
- 置信度低；
- 经济逻辑清楚；
- 不依赖未验证因子；
- 更适合解释和展示。

即使它不是收益最高，也可能是更稳健的主模型。

## 14. 如何写进最终报告或面试项目介绍

可以这样表述：

> 我没有把回测收益最高的模型直接当作最终策略，而是同时比较收益、波动、回撤、换手、交易成本和可解释性。结果显示 Minimum Variance 和 Risk Parity 在风险调整后很稳健，而 Conservative BL 提供了可解释的宏观观点整合框架。Custom Factor Views 只作为低置信度情景分析，不被解释为强 alpha。

## 15. 项目局限性

- 回测使用日频数据；
- 期货数据是免费连续合约代理；
- 交易成本简化；
- 未建模滑点、税费、保证金；
- 比特币和期货交易时间不同；
- custom factor 未经过强统计验证；
- rolling backtest 不能保证未来表现。
