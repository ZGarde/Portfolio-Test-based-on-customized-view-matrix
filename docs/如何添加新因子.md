# 如何添加新因子

## 一、新因子添加流程

### Step 1：明确因子经济逻辑

先回答：

- 这个因子想解释什么？
- 它影响哪个资产？
- 它是风险偏好、避险、动量、宏观、跨市场还是情绪因子？
- 它预测收益、波动、相关性还是风险暴露？
- 是否有明确经济机制？

如果没有清晰经济逻辑，不建议进入 Black-Litterman views。

### Step 2：准备原始数据

检查：

- 数据来源是否可靠；
- 数据频率是日频、分钟频还是事件频；
- 日期字段是什么；
- 是否有时区问题；
- 是否有收盘时间差；
- 是否有缺失值；
- 是否需要对齐到交易日；
- 是否能在调仓时点之前获得。

### Step 3：写因子计算逻辑

需要明确：

- 因子值如何计算；
- 是否使用 rolling window；
- 是否 winsorize；
- 是否 z-score 标准化；
- 是否需要 `shift` 或 `lag`；
- 是否避免未来函数。

### Step 4：加入 `clean_factor_panel.csv`

新因子应该：

- 使用清晰字段名，例如 `dxy_change_5d`；
- 按 `date` 对齐；
- 不破坏已有字段；
- 缺失值保留为 NaN，不随便填充；
- 如果是交易日前可知数据，要严格记录 lag。

### Step 5：做因子检验

至少检查：

- Pearson IC；
- Spearman rank IC；
- qcut 分组收益；
- rolling 252d IC；
- 样本量；
- 缺失率；
- out-of-sample 表现；
- 是否只是某一年有效。

### Step 6：决定因子用途

因子可以分类为：

- `approved_candidate_factor`：严格通过，可进入中高置信度研究；
- `research_only_factor`：有经济逻辑但统计不充分；
- `custom_factor_view`：用户主观低置信度 view；
- 不使用。

### Step 7：如果进入 Black-Litterman View

需要定义：

- 目标资产；
- view 方向；
- view 强度；
- confidence；
- Omega 如何体现置信度；
- absolute view 还是 relative view；
- 是否写入 `custom_factor_views.yaml`。

### Step 8：重新运行项目

```bash
python src/build_clean_factor_panel.py
python src/strict_factor_review.py
python src/build_static_portfolios_bl.py
python src/run_rolling_backtest_bl.py
```

## 二、新因子代码模板

```python
import pandas as pd
import numpy as np


def winsorize_series(series: pd.Series, lower=0.01, upper=0.99) -> pd.Series:
    """中文说明：对极端值做截尾，避免少数异常点主导因子。"""
    lo, hi = series.quantile([lower, upper])
    return series.clip(lo, hi)


def zscore_series(series: pd.Series, window: int = 252) -> pd.Series:
    """中文说明：使用滚动均值和标准差做标准化，只使用过去窗口。"""
    mean = series.rolling(window, min_periods=60).mean()
    std = series.rolling(window, min_periods=60).std()
    return (series - mean) / std


def build_new_factor(raw_path: str, factor_panel: pd.DataFrame) -> pd.DataFrame:
    """
    中文说明：
    这个函数用于构建一个新的示例因子。

    输入：
    - raw_path: 原始数据路径
    - factor_panel: 已有 clean factor panel

    输出：
    - 增加新因子列后的 factor_panel

    注意：
    - 不使用未来收益；
    - 如果数据在次日才可获得，需要 shift(1)；
    - 不随便 forward fill 资产收益；
    - 保留缺失值并在质量报告中解释。
    """
    raw = pd.read_csv(raw_path, parse_dates=["date"])
    raw = raw.sort_values("date").set_index("date")

    raw["raw_change"] = raw["value"].pct_change(fill_method=None)
    raw["raw_change_winsorized"] = winsorize_series(raw["raw_change"])
    raw["new_factor_zscore"] = zscore_series(raw["raw_change_winsorized"])

    # 如果该数据在收盘后或次日才可获得，必须滞后。
    raw["new_factor_lag1"] = raw["new_factor_zscore"].shift(1)

    factor_panel = factor_panel.join(raw[["new_factor_lag1"]], how="left")

    non_null_ratio = factor_panel["new_factor_lag1"].notna().mean()
    print(f"new_factor_lag1 non-null ratio: {non_null_ratio:.2%}")
    return factor_panel
```

## 三、Custom View 配置模板

```yaml
use_custom_factor_views: true

custom_views:
  - name: example_factor_to_gold
    enabled: true
    factor_file: data/processed/clean_factor_panel.csv
    factor_column: example_factor_lag1
    affected_asset: Gold
    direction: positive
    lag_days: 1
    view_type: absolute
    expected_return_impact_annualized: 0.010
    confidence: 0.10
    max_confidence: 0.30
    description: "中文解释这个因子的经济逻辑。"
```

字段解释：

| 字段 | 含义 |
|---|---|
| `use_custom_factor_views` | 是否启用 custom views |
| `name` | view 名称 |
| `enabled` | 是否启用该 view |
| `factor_file` | 因子文件路径 |
| `factor_column` | 因子列名 |
| `affected_asset` | 影响资产 |
| `direction` | 正向或负向 |
| `lag_days` | 滞后天数 |
| `view_type` | absolute 或 relative，目前主要使用 absolute |
| `expected_return_impact_annualized` | 年化 view 强度 |
| `confidence` | 置信度 |
| `max_confidence` | 最大置信度，上限 0.30 |
| `description` | 中文经济逻辑说明 |

## 四、新因子检查清单

- 是否有未来函数；
- 是否 lag；
- 是否和目标资产日期对齐；
- 是否缺失值过多；
- 是否极端值过多；
- 是否经济逻辑合理；
- 是否统计检验通过；
- 是否只是短期偶然有效；
- 是否会导致过度换手；
- 是否会导致组合过度集中；
- 是否应该只是 research only；
- 是否适合进入 Black-Litterman。

## 五、示例：VIX 上升时提高国债和黄金观点

### 因子逻辑

当 VIX 上升，市场风险偏好下降。理论上可以提高黄金和美国国债的防御性 views，降低纳斯达克和比特币的风险资产 views。

### 数据字段

当前项目已有：

```text
clean_factor_panel.csv -> vix_change
```

### 计算公式

```text
vix_change = vix_level.diff()
```

### 配置文件

```yaml
custom_views:
  - name: vix_to_treasury
    enabled: true
    factor_file: data/processed/clean_factor_panel.csv
    factor_column: vix_change
    affected_asset: Treasury
    direction: positive
    lag_days: 1
    view_type: absolute
    expected_return_impact_annualized: 0.010
    confidence: 0.10
    max_confidence: 0.30
    description: "VIX 上升代表风险偏好下降，低置信度提高美国国债预期收益。"
```

### 运行

```bash
python src/build_static_portfolios_bl.py
python src/run_rolling_backtest_bl.py
```

### 检查输出

查看：

```text
custom_factor_view_log.csv
rolling_backtest_custom_factor_log.csv
bl_weights_custom.csv
rolling_backtest_performance_summary.csv
```

### 解释结果

如果 Custom BL 表现改善，不能直接说明 VIX 因子是强 alpha。它只说明这个低置信度情景在样本中可能有帮助，还需要更严格的样本外检验。
