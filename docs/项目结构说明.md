# 项目结构说明

```text
multi_asset_factor_project/
    config/
        custom_factor_views.yaml
    data/
        raw/
        processed/
            charts/
    docs/
    reports/
    src/
        factors/
    requirements.txt
    README.md
    README_CN.md
```

## `config/`

保存用户配置。

| 文件 | 说明 |
|---|---|
| `custom_factor_views.yaml` | 用户自定义低置信度 Black-Litterman 因子观点 |

## `data/raw/`

保存原始数据。

| 文件 | 说明 |
|---|---|
| `us_asset_prices.csv` | yfinance 下载的资产价格 |
| `fred_rates.csv` | FRED 利率 |
| `china_gold_sge.csv` | akshare 中国黄金代理数据 |

## `data/processed/`

保存所有中间结果和最终结果。

主要类别：

- 收益率文件；
- 因子面板；
- 因子审查报告；
- 静态组合输出；
- rolling 回测输出；
- 图表。

## `reports/`

保存 Markdown 报告。

| 文件 | 说明 |
|---|---|
| `stage2_black_litterman_static_summary.md` | Stage 2 静态 BL 报告 |
| `stage3_rolling_backtest_summary.md` | Stage 3 回测总结 |
| `stage3_backtest_audit_report.md` | Stage 3 实现审查报告 |

## `src/`

保存 Python 代码。

| 脚本 | 说明 |
|---|---|
| `get_data.py` | 下载数据 |
| `build_clean_factor_panel.py` | 清洗和质量报告 |
| `strict_factor_review.py` | 严格因子审查 |
| `build_static_portfolios_bl.py` | Stage 2 静态 BL |
| `run_rolling_backtest_bl.py` | Stage 3 rolling 回测 |

## `src/factors/`

按资产类别拆分因子逻辑。

| 文件 | 说明 |
|---|---|
| `gold_factors.py` | 黄金因子 |
| `bond_factors.py` | 债券和利率因子 |
| `vix_factors.py` | VIX 因子 |
| `btc_factors.py` | 比特币因子 |
| `oil_factors.py` | 原油因子 |
| `equity_factors.py` | 权益和风险偏好因子 |
| `common.py` | 通用函数 |

## 命名不一致说明

用户需求中提到的 `clean_price_panel.csv` 和 `clean_return_panel.csv` 当前项目未生成。当前对应文件为：

- 价格：`data/raw/us_asset_prices.csv`
- 初步收益：`data/processed/returns.csv`
- BL 对齐收益：`data/processed/asset_returns.csv`

后续如果希望命名更统一，可以新增这两个文件作为别名输出。
