# 中文使用教程：从运行项目到看懂回测结果

这份教程按“小白视角”写。你不需要一开始理解所有金融模型，只要按步骤运行、看输出文件、看图表，就能知道项目是否跑通，以及结果应该怎么解释。

## 0. 你刚遇到的 PermissionError 是什么？

如果你运行：

```bash
python src/run_rolling_backtest_bl.py
```

看到类似报错：

```text
PermissionError: [Errno 13] Permission denied:
data/processed/rolling_backtest_positions.csv
```

这通常不是策略逻辑错，也不是 Black-Litterman 算错了，而是 **Windows 不允许 Python 覆盖一个正在被打开的 CSV 文件**。

最常见原因：

- 你用 Excel 打开了 `rolling_backtest_positions.csv`；
- VS Code / Cursor 正在预览这个 CSV；
- Power BI、WPS、Notepad++ 或其他程序占用了文件；
- OneDrive / 同步软件正在锁定文件；
- 上一次 Python 进程还没有完全退出。

解决方法：

1. 关闭所有打开的 CSV 文件，尤其是：

```text
data/processed/rolling_backtest_positions.csv
data/processed/rolling_backtest_equity_curve.csv
data/processed/rolling_backtest_performance_summary.csv
```

2. 如果不确定哪个文件被占用，先关闭 Excel、WPS、Power BI，以及编辑器里的 CSV 预览。

3. 回到项目根目录：

```bash
cd "e:\Projects\Port Project\multi_asset_factor_project"
```

4. 重新运行：

```bash
python src/run_rolling_backtest_bl.py
```

小技巧：运行脚本时，不要同时打开 `data/processed/` 里的 CSV。先运行，等脚本完成后再打开结果。

## 1. 项目到底在做什么？

这个项目做的是多资产组合研究。资产包括：

- 黄金
- 美国国债
- 比特币
- 原油
- 纳斯达克

项目大概分三步：

1. 先下载数据、计算收益率、构建因子；
2. 用 Black-Litterman 和其他组合方法生成权重；
3. 做 rolling 回测，看这些组合方法历史上表现如何。

你可以把它理解成：

> 我们不是直接预测明天涨跌，而是先构建一套多资产研究框架，再比较不同组合构建方法在样本外历史数据中的表现。

`portfolio_weights_static.csv`

`portfolio_ex_ante_performance.csv`

## 7. 回测结果先看哪个文件？

最重要的是：

```text
data/processed/rolling_backtest_performance_summary.csv
```

建议用 Excel 打开。先看这些列：

| 列名 | 中文含义 | 怎么看 |
|---|---|---|
| `strategy` | 策略名称 | 比如 Minimum Variance、Risk Parity、BL Conservative |
| `window` | rolling 窗口 | 252 约等于一年，504 约等于两年 |
| `rebalance_frequency` | 调仓频率 | monthly 或 quarterly |
| `final_portfolio_value_net` | 扣成本后的最终净值 | 初始资金是 1,000,000，越高越好，但不能只看它 |
| `annualized_return_net` | 扣成本后的年化收益 | 越高越好 |
| `annualized_volatility` | 年化波动率 | 越低越稳 |
| `sharpe_ratio_net` | 扣成本后的夏普比率 | 风险调整后收益，越高通常越好 |
| `max_drawdown` | 最大回撤 | 越接近 0 越好，例如 -0.20 比 -0.45 稳 |
| `average_turnover` | 平均换手率 | 越高交易越频繁 |
| `total_transaction_cost` | 总交易成本 | 看策略是否被交易成本侵蚀 |

最简单的看法：

1. 先按 `sharpe_ratio_net` 从高到低排序；
2. 再看 `max_drawdown` 是否太大；
3. 再看 `final_portfolio_value_net`；
4. 最后看 `average_turnover` 和 `total_transaction_cost`。

不要只看最终净值。一个策略最终净值高，但最大回撤很大，也可能不适合稳健投资组合。

## 9. 如何看 custom factor 有没有被用？

打开：

```text
data/processed/rolling_backtest_custom_factor_log.csv
```

重点列：

| 列名 | 含义 |
|---|---|
| `rebalance_date` | 调仓日 |
| `factor_name` | custom factor 名字 |
| `factor_date_used` | 实际使用的因子日期 |
| `factor_value_used` | 实际使用的因子值 |
| `affected_asset` | 影响哪个资产 |
| `Q_annualized` | 转成 BL view 后的年化观点 |
| `confidence` | view 置信度 |
| `view_status` | active 表示生效 |

重点检查：

```text
factor_date_used < rebalance_date
```

如果成立，说明没有用未来因子。

## 10. 一个完整使用例子：启用 VIX 因子影响 Nasdaq

假设你想测试这个研究观点：

> VIX 上升代表风险偏好下降，因此低置信度降低 Nasdaq 的 Black-Litterman 预期收益 view。

### 第一步：打开配置文件

```text
config/custom_factor_views.yaml
```

找到：

```yaml
- name: vix_to_nasdaq
  enabled: false
```

改成：

```yaml
- name: vix_to_nasdaq
  enabled: true
```

保持这些配置：

```yaml
factor_column: vix_change
affected_asset: Nasdaq
direction: negative
lag_days: 1
confidence: 0.15
max_confidence: 0.30
```

含义：

- `vix_change > 0` 时，降低 Nasdaq 的预期收益 view；
- `lag_days: 1` 表示 rolling 回测只能用 t-1 或更早数据；
- `confidence: 0.15` 表示这是低置信度研究观点，不是强信号。

### 第二步：重新跑静态 BL

```bash
python src/build_static_portfolios_bl.py
```

查看：

```text
data/processed/custom_factor_view_log.csv
data/processed/bl_weights_custom.csv
```

### 第三步：重新跑 rolling 回测

运行前请关闭所有 CSV 文件。

```bash
python src/run_rolling_backtest_bl.py
```

查看：

```text
data/processed/rolling_backtest_custom_factor_log.csv
data/processed/rolling_backtest_performance_summary.csv
data/processed/charts/rolling_cumulative_net_returns_comparison.png
```

### 第四步：怎么判断这个因子有没有帮助？

比较这两个策略：

- `BL Conservative`
- `BL Custom Factor Views`

重点比较：

```text
annualized_return_net
sharpe_ratio_net
max_drawdown
average_turnover
total_transaction_cost
```

如果 Custom BL 表现更好，也不能直接说 VIX 因子是强 alpha。只能说：

> 在当前样本中，这个低置信度 scenario view 对组合有帮助，需要继续样本外检验。

如果 Custom BL 表现更差，也不一定说明因子完全没用，可能是：

- view 方向不稳定；
- confidence 设得不合适；
- 样本期市场环境不支持；
- 交易成本或权重约束抵消了效果。

## 11. 常见指标解释

| 指标 | 含义 | 解读 |
|---|---|---|
| `annualized_return_net` | 扣成本后年化收益 | 越高越好，但要结合风险 |
| `annualized_volatility` | 年化波动率 | 越高说明净值波动越大 |
| `sharpe_ratio_net` | 扣成本后夏普 | 风险调整收益，越高越好 |
| `max_drawdown` | 最大回撤 | 越接近 0 越稳 |
| `turnover` | 换手率 | 越高交易越频繁 |
| `transaction_cost` | 交易成本 | 高换手策略会被成本侵蚀 |
| `gross_return` | 成本前收益 | 看策略本身 |
| `net_return` | 成本后收益 | 更接近真实表现 |

## 12. 常见报错

| 报错 | 可能原因 | 处理 |
|---|---|---|
| `PermissionError` | CSV 被 Excel、VS Code、Power BI 占用 | 关闭文件后重新运行 |
| `missing raw price file` | 未运行 `get_data.py` | 先下载数据 |
| `missing clean_factor_panel.csv` | 未运行 Stage 1 clean 脚本 | 运行 `build_clean_factor_panel.py` |
| YAML 读取错误 | 配置缩进错误 | 检查 `config/custom_factor_views.yaml` |
| 图表无法生成 | 某类数据为空 | 一般不影响主结果 |
